# Animation Update: Zero I/O Friction

I improved the `draw-fast-io` animation in
`src/bb_web_ds_tools/components/landing.cljs` to better visualize the concept
of "Zero I/O Friction".

## Changes

*   **Replaced** the static path drawing with a multi-phase animation.
*   **Phase 1 (Browsing):** Simulates a window with multiple tabs, switching
    between them to show different data sources.
*   **Phase 2 (Selection & Copy):** Highlights the content and displays a
    "COPY" overlay.
*   **Phase 3 (Transition):** Animates the window shrinking/imploding into the
    center.
*   **Phase 4 (Result):** Displays the final Clojure data structure (`[{:name
    "Data" :value 42}]`) fading in.

## Goal

To convey the ease of taking data from any source (like browser tabs) and
instantly converting it into usable Clojure data structures via copy-paste.

## Update: Syntax Highlighting & Multi-Map Result

Further refined the `draw-fast-io` animation (Phase 4):
*   **Multi-Map:** Now displays a vector of maps `[{:n "A" ...} {:n "B" ...}]`
    instead of a single map.
*   **Syntax Highlighting:** Implemented manual token drawing to apply
    distinct colors to brackets, keywords, strings, and numbers, matching the
    Zenburn theme.

## Update: Transparent Background and Larger Scale for Key Animations

Modified `draw-fast-io`, `draw-instant-charts`, and `draw-multi-runtime`
functions to:
*   **Transparent Background:** Removed `(clear-rect ctx w h)` calls to allow
    backgrounds to be transparent.
*   **Larger Scale:** Increased the size or applied a global scale
    transformation to make the animations bigger and more prominent.

## Fix: Transparency and Scaling Issues

Corrected the previous update which caused "broken" animations due to smearing
and clipping.
*   **Restored `(clear-rect ...)`**: Essential for transparency; clears the
    previous frame so new frames don't smear.
*   **Adjusted Sizing Manually**: Removed the global `.scale(1.5)` which was
    causing clipping. Instead, increased internal dimensions (`win-w`,
    `box-size`, `plot-w`, `font-size`) to make the content larger while
    fitting comfortably within the 256x256 canvas.

## Feature: Mobile Swipe Carousel for Product Tour

Updated `src/bb_web_ds_tools/views/landing.cljs` to enable touch interactions
for the Product Tour section on mobile devices.
*   **Swipe Gestures:** Implemented `touchstart`, `touchmove`, and `touchend`
    handlers to detect left/right swipes on the feature preview card.
*   **Carousel Logic:** Swiping updates the active feature index, cycling
    through the features list.
*   **Mobile Optimizations:**
    *   Hid the text-based feature list on mobile screens (`lg:hidden` for the
        list).
    *   Added visual dot indicators below the card on mobile to show the
        current position and total count.
    *   Added `touch-pan-y` to ensure vertical scrolling still works while
        swiping horizontally.

## Fix: Undeclared Variable in Landing View

Fixed a compilation warning in `src/bb_web_ds_tools/views/landing.cljs`:
*   Replaced the undeclared `t/bg-muted` variable with `t/bg-button` for the
    inactive carousel indicators.

## Feature: Carousel Indicators on All Screen Sizes

Modified `src/bb_web_ds_tools/views/landing.cljs` to ensure the product tour
carousel indicators (dots) are visible on all screen sizes by removing the
`lg:hidden` class from their container.

## Refactor: Landing Page Namespaces

Refactored `src/bb_web_ds_tools/views/landing.cljs` and
`src/bb_web_ds_tools/components/landing.cljs` into smaller, more maintainable
namespaces.

*   **Components:**
    *   `src/bb_web_ds_tools/components/landing/animations.cljs`: Extracted
        all `draw-*` animation functions.
    *   `src/bb_web_ds_tools/components/landing.cljs`: Kept only generic
        components (`canvas-card`, `animated-icon`).

*   **Views:**
    *   `src/bb_web_ds_tools/views/landing/background.cljs`: Extracted
        background animation logic.
    *   `src/bb_web_ds_tools/views/landing/features.cljs`: Extracted features
        carousel logic.
    *   `src/bb_web_ds_tools/views/landing/tour.cljs`: Extracted product tour
        logic.
    *   `src/bb_web_ds_tools/views/landing.cljs`: Now orchestrates the landing
        page by importing the sub-views.
