# Changelog View

## Why?

So you can reminisce about the bugs we used to have before we replaced them with new, more exciting bugs. It's a historical record of our failures and occasional triumphs, mostly failures. Read it and weep.

The **Changelog View** provides a chronological record of changes made to the application, helping users stay informed about new features, improvements, and bug fixes.

## Features

-   **Categorized Entries**: Updates are grouped by type (e.g., `Added`, `Changed`, `Fixed`) for clarity.
-   **Version Tracking**: Each release is clearly versioned and dated.
-   **Linkable**: Specific versions or changes may be linked (if supported) for reference.

## Usage

1.  Navigate to the **Changelog** view via the main navigation menu or footer link.
2.  Scroll through the timeline to review past updates.
3.  Newest changes appear at the top.
